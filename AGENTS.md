# Contexto del proyecto
- El lenguaje principal del proyecto es C++.
- El código importante está en `src/generation/`. Empieza siempre por ahí.
- Ignora el resto de carpetas, salvo que sea necesario para completar la tarea
  (por ejemplo, si algo de `src/generation/` importa o depende de ellas).
- Si necesitas salir de `src/generation/`, hazlo solo para leer lo mínimo
  y avísame qué archivos consultaste y por qué.
- No modifiques archivos fuera de `src/generation/` sin preguntarme antes.
